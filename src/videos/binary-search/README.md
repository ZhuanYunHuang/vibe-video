# 《二分查找》（BinarySearch）

> 一句话定位：不写公式、不讲复杂度，用"排队找人"这一个生活比喻把二分查找讲透。

## 这是什么

一支算法科普短片，主角是一只叫 Clawd 的像素小人，要在 15 个排好队的小伙伴里找到"81 号"。

叙事从"笨办法"到"聪明办法"再到"落到代码"：

1. 排队找人：15 人列队，主角登场说要找 81 号。
2. 笨办法：从头一个一个问，问了 13 次才找到。
3. 灵光一闪：号码是排好序的！那就先问正中间那个。
4. 一刀切一半：问中间 → 淘汰一半 → 再问中间，真正跑一遍二分，只需 4 次。
5. 差距有多大：人数涨到 10 亿，二分次数也才 30 次（O(log n)）。
6. 回到计算机：队伍 = 有序数组、号码 = 元素、站位 = 下标，lo/hi/mid 三指针现场演示。
7. 写成代码：逐行打出二分查找代码，再用真实执行步骤跑一遍（高亮行 + 变量面板）。
8. 结尾：三条要点 + 全员谢幕。

## 怎么做

- **组装方式**：同其它业务——`spec.ts` 给出一份 `VideoSpec`，`src/shared/Video.tsx` 通用装配器拼片；业务侧只从 `../../../shared` 取件。
- **专属 `kit/`**：这是**唯一带业务级 `kit/` 目录**的视频，把"比喻世界"的基础设施沉淀下来：
  - `kit/theme.ts`：专属配色 `P` + 排队队形常量（`NUMS` 15 个号码、`TARGET 81`、`TARGET_IDX`、`QX` 站位函数、地面高度等）。
  - `kit/Clawd.tsx`：像素小人组件（SVG 绘制，支持 mood / 走路 / 跳跃 / 压扁 / 眨眼 / 举手等姿态）。
  - `kit/Queue.tsx`：队伍渲染器，吃一个 `get(i)` 回调，每帧决定第 i 个小伙伴的位置与状态。
  - `kit/ui.tsx`：业务级 UI（`Bubble` 对话气泡、`Sub` 字幕、`Chapter` 章节标签、`Goal` 目标卡、`Confetti` 彩纸、`PaperBackdrop` 背景、`ClawdHud` 自定义 HUD，以及 `usePulse` / `useBounce` / `walkPath` 等动画工具）。
- **画面连续性**：排队的 4 幕（02–05 附近）共用**同一队形**，用 `fade` 交叉淡入切换，画面不跳、小明连续走动。
- **节拍卡点**：BGM 为 `public/binary-search/bgm.mp3`（`bpm 112.8 / offset 12`）。场景内用 `useT()` / `useAt(start, k)` 把每次"问话"、每次"淘汰一半"都卡在拍上；`usePulse` 让动作跟着节拍呼吸。
- **注册**：在 `src/videos/index.ts` 的 `VIDEOS` 数组里（当前第三位）。

## 采用什么风格

**暖白纸面 + Claude 陶土橙**（唯一做自定义风格覆盖的业务）：

- **配色**：专属 `P` 调色板——底色 `P.bg #F3EEE6`，主色陶土橙 `P.clay #D97757`，墨色 `P.ink`，点缀天空蓝 / 鼠尾草绿 / 金 / 玫瑰红。
- **背景层**：自定义 `Backdrop: PaperBackdrop`——暖白纸面 + 浅点阵，替代默认的深蓝霓虹网格。
- **HUD**：自定义 `Hud: ClawdHud`——底部一根细进度条（陶土橙），末端有一只跟着节拍小跳的迷你小人，替代默认的切场闪白进度条。
- **退场**：`exitDim: 0`——暖色纸面风格不做退场压暗。
- **视觉母题**：像素小人 Clawd 作为全程主角；手绘感的粗描边卡片 + 圆角气泡 + 有序队伍，整体是"绘本 / 纸面"气质，而不是赛博霓虹。
- **转场**：以 `fade` / `circle` / `slideUp` / `slideLeft` 为主，配合画面连续性需求。

## spec 关键参数

| 字段 | 值 | 说明 |
|---|---|---|
| id | `BinarySearch` | Composition id（全局唯一） |
| bpm / offset | `112.8` / `12` | BGM 节拍与首拍帧 |
| totalBeats | `336` | 正片总拍数 ≈ 178.7s |
| transFrames | `12` | 转场帧数 |
| tailFrames | `30` | 结尾留白 |
| bgm | `binary-search/bgm.mp3` | 相对 `public/` 的路径 |
| bg | `P.bg`（`#F3EEE6`） | 暖白纸面底色 |
| width × height | `1920 × 1080` | FPS 30 |
| Backdrop | `PaperBackdrop` | 自定义浅点阵背景 |
| Hud | `ClawdHud` | 自定义进度条 + 迷你小人 |
| exitDim | `0` | 不压暗退场 |
