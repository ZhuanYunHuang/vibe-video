# 《二维码会被用完吗？》（Qrcode）

> 一句话定位：从黑白格子的二进制原理讲起，用一套数学推导回答"二维码够不够用"。

## 这是什么

一支 IT 科普短片，回答一个很多人好奇过的问题：**二维码每天被扫这么多次，会不会有一天被用完？**

叙事从"是什么"一路推到"够不够用"：

1. 开场抛出问题：每天被扫无数次的方块，会被用完吗？
2. 二进制原理：白 0 黑 1，几个格子就能拼出字母。
3. 结构：三个定位角先定方向，剩下格子才装数据。
4. 版本：格子从 21×21 到 177×177，容量差约 71 倍。
5. 容量：一个二维码最多能装 7,089 个数字。
6. 组合数：可能是天文数字 2^208 ≈ 10^62。
7. 消耗速度：全人类一年也才扫 10^11 个。
8. 数学结论：要 10^51 年才扫得完，比宇宙年龄还大 10^41 倍。
9. 总结：根本用不完，放心扫。

## 怎么做

- **组装方式**：同 web-request——`spec.ts` 给出一份 `VideoSpec`，`src/shared/Video.tsx` 通用装配器据此拼片；业务侧只从 `../../../shared` 取件。
- **场景编排**：9 个场景，每个场景一个文件（`scenes/*.tsx`），统一 `React.FC<SceneProps>`。
- **节拍卡点**：BGM 为 `public/qrcode/bgm.mp3`（与 web-request 同源，`bpm 112.8 / offset 12`，复用同一段音乐）；全程用 `useAt()(start, k)` 把每个数字 / 卡片 / 结论的出场精确卡在拍上。
- **组件与工具**：大量自绘的点阵 / 卡片 / 对比条（业务内实现）；章节标题用 `SceneTitle`，字幕用 `Caption`，动画用 `pop / prog / hit`，开场标题用 `Center`。
- **注册**：在 `src/videos/index.ts` 的 `VIDEOS` 数组里（当前第二位）。

## 采用什么风格

**默认霓虹网格风格 + 章节色**（不覆盖 `Backdrop` / `Hud`）：

- **背景层**：默认 `BeatGrid`，深蓝网格随节拍呼吸。
- **配色**：默认 `C` 调色板；配色承担"信息角色"——二进制用青、结构用紫、版本用绿、容量用黄、消耗用粉、结论用橙/绿。
- **章节色**：靠 `scenes[].bg` 给每一章换一个深色底（`#0d1430` / `#120f2e` / `#0a1a2a` / `#0b1f1a` / `#1f1a0b` / `#1f0b1a` / `#1f140b`），营造"一章一色"的推进感。
- **HUD**：默认 `ProgressHud`（切场闪白 + 渐变进度条）。
- **视觉母题**：等宽字体（`MONO`）呈现数字与算式，配合发光文字 / 增长条 / 对比条，突出"数学推导"的理性气质。

## spec 关键参数

| 字段 | 值 | 说明 |
|---|---|---|
| id | `Qrcode` | Composition id（全局唯一） |
| bpm / offset | `112.8` / `12` | BGM 节拍与首拍帧 |
| totalBeats | `280` | 正片总拍数 ≈ 149s |
| transFrames | `12` | 转场帧数 |
| tailFrames | `45` | 结尾留白 |
| bgm | `qrcode/bgm.mp3` | 相对 `public/` 的路径 |
| bg | `C.bg`（`#0b1020`） | 整片底色 |
| width × height | `1920 × 1080` | FPS 30 |
| 风格覆盖 | 无 | 使用默认 `BeatGrid` + `ProgressHud` |
