> 一句话结论：现有版本是「**剧情壳 + 讲解芯**」的混合体——拍号骨架是对的，但**内容在讲道理、视觉语言分裂、多处构图空洞**，所以看起来像"会动的 PPT"。本次重规划**保留已与 BGM 验证过的拍号骨架（304 拍 / 112.8bpm）**，把内容重写成一支**单一视觉语言、情绪连贯、故事优先**的 2:43 短片。

## 二、重规划方案

### 2.1 叙事：从"讲道理"到"演一遍，再演一遍"
情绪短片的力量来自**事件**而非**结论**。重规划的三条主线：
1. **敬题"耐心电量"**：让电量条成为**贯穿全片的计时器/钟表**（≥10 幕出现，含封面），观众随时知道"还剩下多少"。
2. **四因戏剧化**：4 个「原因」不再用静态卡片讲，而是**在场景里演出来**（日志滚动 / 橡皮筋绷断 / 期待尺对比 / 面具摘下）。
3. **方法论用"重来一次"**：3 个「方法」统一标记为**同一晚的重演**（画面打「重来一次」印章），观众看到的不是新事件，而是"如果能重来"，情绪落点更强。

**保留骨架**：`scenes[].start/end` **一个都不改**（已与 BGM 卡点验证）；只重写每幕的内容、镜头与 kit 组件。**不新增场景文件**（避免 spec 引用变动），只重写现有文件。

### 2.3 视觉语言统一（去掉"两套皮"）
1. **只保留两个世界**：冷（夜城/门外）与暖（家/门内）。**删除分析幕的"浅蓝白纸面"背景**（`ReasonOne/Two/Three/Four` 改画在场景里）。
2. **所有图表"落进场景"**：白卡 / 胶囊 / 尺 / 印章，与 `Battery` 同一套语言（描边 + 柔投影 + 斜角微旋），不再是"浮在白纸上的文本框"。
3. **加深度**：每幕拆「背景层 / 中景层 / 前景层」，用 shared 的 `ParallaxLayers` 做视差；统一 `vignette` 暗角；夜城楼群分两层、客厅墙与家具分两层。
4. **加镜头**：关键幕用 `FocusZoom` / `ShakeWrapper` / `Shockwave`（已在 `shared` 现成）；重转场只放在 ★ 处。
5. **灯光隐喻**：门内暖光 / 门外冷光作为"内外"的贯穿符号（`WhyTitle` 的对切、`MethodOne` 的回充都靠它）。

## 五、验证方式（严格按序）

1. **静态自检**（改完即跑）：`npm run typecheck` 退出码必须为 0。
2. **骨架自检**：确认 `scenes[].start` 全为 16 的倍数、连续无空洞、`totalBeats % 16 === 0`、`totalBeats ≤ 361`；每个 16 拍边界都有"切场转场"或"内容跳变"（对照 2.2 表的"幕内跳变点"）。
3. **抽帧查碰撞**（重点）：对每幕各抽 1–2 帧，检查元素重叠/空洞：
   `npm run still -- PatienceBattery out/patience-battery/check-<幕名>.png --frame=<关键帧>`
   封面必查：副标题 vs 夜城招牌、电池卡 vs 人物躯干。
4. **预览通看**：`npm run preview` → 用 `http://127.0.0.1:5180/?v=PatienceBattery&debug=1` 逐幕（`[ ]` 切场、`1–9` 跳场）完整过一遍，确认节奏无"干等"。
5. **封面导出**：`npm run still -- PatienceBatteryCover out/patience-battery/cover.png`。
6. **渲染成片**（**必须等你确认后**）：`npm run render -- PatienceBattery out/patience-battery/patience-battery.mp4`。
