# 《升本后醒来》动画 MV 制作计划（v3 · 完整歌词 + 四大重拍）

## Summary

用户上传成都 HIPHOP 现场《升本后醒来》live 视频，要求用其音乐做**动画版、有剧情**的 MV，并提供了**完整权威歌词**与**四个重拍卡点**。本项目为 Remotion 视频工厂，本任务即新增一支视频业务 `shengben`：抽原曲音轨作 BGM，按 123bpm 节拍网格（★=切场 / 强拍=幕内炸裂）编排分镜，用程序化霓虹嘻哈动画演绎"自嘲 → 兄弟 → 死磕 → 上岸凡尔赛 → 反转 → 宣言"的故事。

> v3 相对 v2：① 替换为**用户提供的完整权威歌词**（修正/补齐字幕漏转写的行）；② 新增**四个重拍炸裂点**（b8/b40/b56/b104）的详细处理方案；③ punchline「学英语我用的原神的英文版」专门突出。

## 二、四大重拍炸裂点（本版核心）

四个点都验证为**强拍**（非 16 倍数）→ 一律做成**幕内炸裂跳变**，不硬切场（场景切换仍只在 ★）。

| # | 拍号/秒 | 位置 | 歌词 | 炸裂处理 |
|---|---|---|---|---|
| ① | b8 / 4.3s | Scene1（0–32） | 「不能本升专」的**专** | 全屏白闪 + 冲击波环 + 大字「专」glitch 砸向屏幕 + 校门碎裂；镜头内容级震屏 |
| ② | b40 / 19.9s | Scene2（32–48） | **狂** | 巨大霓虹「狂」字（描边抖动）砸入占满画面 + 品红闪屏 + 火花粒子；主角后仰指天定格 |
| ③ | b56 / 27.7s | Scene3（48–64） | **唉** | 画面瞬间失焦转灰白 + 巨型「唉」叹息砸入 + 下坠情绪线；随即兄弟入镜恢复彩色 |
| ④ | b104 / 51.2s | Scene5（96–128） | **学英语我用的原神的英文版** | **punchline 特效**：0.5s 静帧冻结 + 画面缩放推近 + 弹「PUNCHLINE」徽章 + 原神风游戏图标 + 字幕加粗高亮光晕；全场唯一重点标记 |

实现载体：每个场景内用 `k(拍号)` 精确卡帧，叠加 `hit()` 打击脉冲 + 白闪覆盖层 + 内容级 transform 震屏（**不做全屏每拍抖动**，只在炸裂瞬间触发）。

## 四、技术实施步骤

### 步骤 0 · 资源准备
1. 项目自带 ffmpeg（`node_modules/@remotion/compositor-win32-x64-msvc/ffmpeg.exe`，已确认含 libmp3lame 编码器）：
   ```
   ffmpeg -y -i <原视频> -vn -c:a libmp3lame -b:a 192k public/shengben/bgm.mp3
   ```
2. 复制 `src/videos/_template/` → `src/videos/shengben/`

### 步骤 1 · `spec.ts`
- `id:"Shengben"`、`bpm:123`、`offset:13`、`totalBeats:288`、`transFrames:10`、`tailFrames:150`（正片140.9s+5s收尾≈145.9s，吃掉原曲147s尾部）
- `bgm:"shengben/bgm.mp3"`、1920×1080、`bg:P.bg`
- 覆盖 `Backdrop:NeonBackdrop` / `Hud:RapHud` / `exitDim:0.5`
- `scenes[]` 照第三节，start/end 全 16 的倍数；**★/△ 落点与四个炸裂点抄进注释**

### 步骤 2 · kit（`src/videos/shengben/kit/`）
- `theme.ts`：调色板 `P`（`bg:#0b1020`、`cyan:#22e4ff`、`magenta:#ff3ea5`、`yellow:#ffd23f`、`ink:#eaf6ff`）、常量（校门/舞台坐标）
- `Dude.tsx`：**天选之子小人**（Q版说唱小人，姿势：指天/抱臂/蹲/举通知书/背影），参考 `binary-search/kit/Clawd.tsx`
- `Lyric.tsx`：**多行歌词组件**，入参 `lines: { beat:number; text:string; punch?:boolean; punchline?:boolean }[]`；punch 触发炸裂特效，punchline 触发冻结+徽章+高亮；替代单行 `Caption`
- `Fx.tsx`：**炸裂特效库** —— `WhiteFlash`（白闪覆盖层）、`Shockwave`（冲击波环）、`BigWord`（大字砸入+glitch）、`PunchlineBadge`（冻结+徽章+推近）；全部卡 `k()`/`hit()`
- `ui.tsx`：`NeonBackdrop`（深底+霓虹网格呼吸）+ `RapHud`（霓虹渐变进度条+当前拍号）

### 步骤 3 · 场景（`src/videos/shengben/scenes/`，10 幕）
`Intro` / `Sneer` / `Brothers` / `Grind` / `Hustle`+`Admitted` / `Flex` / `Crack` / `Truth` / `Rise` / `Outro`
- 统一 `React.FC<SceneProps>`，从 `../../../shared` import
- 四个炸裂点按第二节规格实现（`Fx` 组件 + `k()` 卡帧）
- 歌词用 `Lyric` 按第一节拍号定位

### 步骤 4 · 注册
- `src/videos/index.ts`：`import { shengben } from "./shengben/spec"`，加入 `VIDEOS`

### 步骤 5 · 封面
- `Cover.tsx`：霓虹背景 + 天选之子小人 + 主标题《升本后醒来》+ 副标题「你能专升本，我不能本升专」；挂 `spec.Cover`

## 五、假设与决策

1. **BGM 用原曲（含人声）**：MV 主题即这首歌，保留 rap 人声，歌词才有意义。
2. **画风霓虹嘻哈**：贴合原 live 舞台气质；如换风格只改 `kit/`，分镜不变。
3. **四个重拍做幕内炸裂而非硬切**：已验证 b8/b40/b56/b104 均为强拍但非 16 倍数，切场只留给 ★，符合 skill 铁律；若实现后发现想在这四拍真切场，需手动偏离该规则（不推荐，会破坏乐句）。
4. **歌词为权威版**：以用户提供为准，替换 v2 的字幕转写；punchline 原句用「原神」（游戏 Genshin）英文版。
5. **BPM 123 为脚本启发式判定**（半速翻倍），top5 候选 61.5/82/92.25 也在晃；成片后目测切点是否落在鼓点，不对试 92.25。
6. **不改 `src/shared/`**：只新增 `src/videos/shengben/`、`public/shengben/` 并改 `src/videos/index.ts`。
7. **`tailFrames:150`**：成片≈145.9s 尽量吃满原曲 147s；仍有截断则渲染前对 bgm `-t` 对齐。
